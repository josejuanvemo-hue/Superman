# 🏋️ GYM TRACKER

App personal de seguimiento de entrenamiento. Rutina de 5 días (Lunes–Viernes) con registro de pesos, series e historial.

## ✨ Features

- Registro de peso por serie en cada ejercicio
- Timer de descanso con sonido al terminar
- Historial de sesiones guardado localmente
- Barra de progreso diario
- 100% offline — sin servidor, sin cuenta, sin nada

## 🚀 Uso

Abre `index.html` en cualquier navegador.  
O accede directo: **[tu-usuario.github.io/gym-tracker](https://tu-usuario.github.io/gym-tracker)**

## 📱 Instalar en iPhone

Safari → Compartir → **Agregar a pantalla de inicio**

Built with vanilla HTML/CSS/JS. No dependencies.
